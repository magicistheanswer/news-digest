Optimizely signup flaw let an attacker inject code into customer projects

CMSWire · Nov 18, 2026
core / martech – experimentation, security

Optimizely says an attacker abused a flaw in its Web Experimentation signup flow on Nov 16 to impersonate users and write malicious JavaScript into the Project JavaScript field of some customers' snippets; it says the hole was closed within three hours and fewer than 5% of customers were affected. Report URI, which first flagged the attack, counts 178 organisations whose visitors received the code – served from Optimizely's own trusted CDN. A strict Content Security Policy is cited as the main defence; per Report URI, 68 of the affected sites had none. Worth a check if you run client-side tag or testing snippets.
